# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

样本体积为uL。transform输入输出是实际物理转化，buffer贡献体积不贡献原样成分；同一原样多条路径不能增加覆盖人数或原样数量。consume不可逆，退回只变保管位置不还原耗用；freeze_thaw按真实冻融次数累计。mix为均匀混合，分取按输入体积比例携带成分，资料不要求推断化学反应；体积不闭合或来源未知则保留不确定贡献。方法M1不接受混池，M2接受混池作定性覆盖但不能反推单样浓度；M2稀释倍数不得超过10，M1不得超过5。qc=failed的运行仍计实际占孔与消耗，不计有效证据；重复导出同run/plate/well/channel/replicate不新计工作。v1通道signal单位ng/mL，v2的mass_concentration为ug/L，数值可比；v2的ratio是无量纲新指标，不能映成旧浓度。合成结果不提供临床解释。raw/instrument.json是原生嵌套输入，保留export_id、run_id、method_version、plates[].wells[].measurements[]层级；run_id区分真实复测，rerun_of不增加原样。

## materials
初始原样与缓冲液。

记录键：['material_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| material_id | string | 根材料 |
| kind | string | sample或buffer |
| project | string | 项目 |
| volume_ul | number | 实收体积 |

## transforms
真实转化，不是自动推导。

记录键：['transform_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| transform_id | string | 动作 |
| kind | string | aliquot或mix或dilute |
| at | datetime | 发生 |

## transform_inputs
原样与子管可同时作为输入但须余额足够。

记录键：['input_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| input_id | string | 行 |
| transform_id | string | 转化 |
| material_id | string | 来源 |
| volume_ul | number | 消耗体积 |

## transform_outputs
真实产管。

记录键：['material_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| material_id | string | 新材料 |
| transform_id | string | 转化 |
| volume_ul | number | 体积 |

## runs
真实执行及复测。

记录键：['run_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| run_id | string | 运行 |
| method | string | 方法 |
| method_version | string | 版 |
| started | datetime | 开始 |
| qc | string | passed或failed |
| rerun_of | string | 原运行 |

## well_inputs
孔内真实消耗，不把导出重复当消耗。

记录键：['input_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| input_id | string | 加样 |
| run_id | string | 运行 |
| plate_id | string | 板 |
| well | string | 孔 |
| material_id | string | 材料 |
| volume_ul | number | 体积 |

## material_events
冻融与位置经历。

记录键：['event_id']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| event_id | string | 事件 |
| material_id | string | 材料 |
| kind | string | freeze_thaw或return或discard |
| at | datetime | 时点 |
| volume_ul | number | 废弃量或空 |

## method_rules
证据使用契约。

记录键：['method']。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| method | string | 方法 |
| allows_pool | boolean | 接受混池 |
| max_dilution | number | 最大稀释倍数 |
| max_freeze_thaw | integer | 最大冻融 |

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

根样本冻融次数从0开始，子管继承每个来源样本自己的经历，缓冲液不计为样本。均匀混合下，稀释倍数为非缓冲原样总体积分数倒数。混池可用只说明定性覆盖，不允许输出各原样浓度。raw/instrument.json为嵌套原始输入。
